# Arsenal

_Manage your installation files easily_.

Arsenal is a tool to organize and manage your installation files, such as .exe, .msi, .dmg, .pkg, and more.
It allows you to keep track of your installation files, categorize them, and easily access them when needed.

## Features

- Organize installation files in a structured manner
- Filter files by name, operating system, category, and more.
- Add notes and tags to files for better organization
- Search for files quickly using the search functionality
